# Arsip Dokumentasi Historis (Documentation Archive)

Direktori ini berisi peta jalan historis, manifest rilis lama, catatan status implementasi terdahulu, dan cetak biru publik legacy. File-file dalam direktori ini dipertahankan khusus untuk penelusuran histori proyek (*traceability*) dan **bukan merupakan panduan aktif proyek**.

Dokumen arsitektur, keamanan, sertifikasi exchange, rilis, dan peta jalan aktif berada di bawah direktori `docs/`.

Satu-satunya peta jalan aktif proyek adalah [`docs/roadmap/ROADMAP-v2.5-PUBLIC-CERTIFICATION.md`](../roadmap/ROADMAP-v2.5-PUBLIC-CERTIFICATION.md).
